# Masterproef-Voetbal-Marktwaarde
Het doel van mijn masterproef was om de determinanten van de marktwaarde voor verdedigers binnen de vijf grootste Europese competities te onderzoeken.

De data is afkomstig van de worldfootballR-bibliotheek van JaseZiv, wat toegang bied tot de FBref 'Big 5 Advanced Season Stats', en de'Player Valuations'-dataset van Transfermarkt.
